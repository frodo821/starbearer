# Starbearer

超光速航行が弾道飛行に限られた銀河で、荷物を運ぶゲーム。移動そのものがゲーム。

## 起動

    dotnet build Starbearer.csproj
    godot-mono --path .

## 操作

画面は目的ごとに四方へ分かれている。左上は時間（停止と再開、時間の速さ、点火へ）と時計、左は航法（軌道・目標・計画、FTL中は予測と周囲の天体）、右上は船（積荷・燃料・船体・熱・生命・モジュール）、右下は操船（姿勢儀・スロットル・姿勢保持、点火や推力と機首のボタン、次のノードの噴射の目安）。下の帯には、港・亜光速・FTL の間を移る操作と表示の切り替えだけを置く。その上の助言が指すボタンは、どこにあっても光る。次のノードがあると、姿勢保持のボタンの上に、最適な点火時刻（噴射の半分をノードの前に）までの時間と残りの噴射時間が、ゲーム内と実時間で並ぶ（点火までの実時間はいまの時間の速さで、噴射の実時間は噴射中の速さで数える）。

時間は長さを `1y 2d 03:04:05.67`（年と日はあるときだけ、1年は365日）、銀河の中の時刻を `Jan, 1st 3456, 07:08:09.12` で書く。銀河の0日目が3456年1月1日0時。

軌道線は閉じた1周ぶんを矢印付きで描く。天体の重力圏を出るなら線はそこで切れ、端に Disengage の時刻、次の星のヒル球に入るなら Encounter の時刻と、その星を通過する軌道が緑で続く（さらに先も最大3星ぶん）。先の軌道にも恒星間の破線にもノードを置ける。無推力の軌道は変わらないので、線の再計算は噴射・ノード編集・主天体の切り替えなどのときだけ行う。

星図は1枚で、亜光速の軌道図を縮小すると銀河まで続き、計画後に発進した場合のFTL経路も見える。FTLの星図を拡大すると港の軌道と、今降下した場合の軌道が見える。

画面下の操作盤はキーと同じ働きをする。その時に押せないボタンは暗くなり、次にやるとよい操作は「次の一手」の文と光るボタンで示す。画面の四隅の括弧は船の状態を色で示し（緑 亜光速、青 FTL、橙 井戸や計画中、赤の点滅 失速の危険）、発進・降下・脱落は全画面の演出で知らせる。

## 基本ルール

- 空間は2層ある。亜光速層は恒星の重力だけの3D軌道力学で、FTL層は弾道飛行。
- 亜光速層は実際の尺度で動く。距離は AU、重力は太陽質量あたり実際の値で、星系は内側の惑星域（質量1の星で約3.25 AU まで）。惑星は火星から数地球、ガス惑星は土星から木星2つ分ほどで、軌道は内から半分〜倍ずつ外へ並ぶ。周期は数か月から数年。亜光速の船は推力 0.01 AU/日²（約0.02g）、満タンで Δv 約 0.08〜0.1 AU/日（約150 km/s）。表示は短い距離を km、亜光速の速さと Δv を km/s で出す。
- 超空間は恒星の近くで縮んでいて、井戸（ly）は星系（AU）の影絵になっている。降下と発進では、位置を 2.5 AU/ly、速さを約0.077倍で写し取るので、軌道の形（離心率と軌道上の位置）は保たれ、大きさと速さだけが変わる。恒星間を亜光速で渡ることはできない（ヒル球を出ても、隣の星まで数千年かかる）。
- 重力は主天体1つだけで解く。ヒル球の内側はその星との2体問題、外側は直進で、ほかの星の影響は受けない。ヒル球の外ではノードを計画できない。
- 発進は港の軌道から。軌道速度がキックに加わるので、向かい風の時機に出ると燃料を損する。
- FTLでは抵抗で速度が距離とともに指数的に落ち、閾値を下回ると失速する。星雲の中は抵抗が強い。
- 恒星の井戸でだけ曲がる。深く通るほど曲がり、井戸の底で噴くほど効率がよく、燃料も吸える。ただし熱い。機首を恒星に向けるとシールドが効く。
- 目的地の井戸で降下すると亜光速の軌道に入る。降下は井戸の中ならどの星でもできる。
- 入港はマニューバノードで港の軌道に合わせ、距離約3,000 km・相対速度約0.35 km/s 以内に収めてから U で入る。範囲に入っても自動では入港しない。最後の詰めは X（接近）と Z（相対速度0）で、押している間だけ機首を向けて噴射し、入港できる速さまで落ちると止まる。点火すると計画軌道は固定され、白線が今止めた場合の軌道になる。ノードの残り Δv は、計画した噴射後の軌道と今止めた場合の軌道との差として毎フレーム測り直すので、狙いのずれや長い噴射中の軌道の曲がりも残りに出て、マーカーを追えば補正できる。エンジンはノードを過ぎても自動では止まらない（残りが機首の後ろへ回ると「過ぎた」と出る）。E で止めたとき、噴射中に残りが計画の1割以下まで減っていればその段は完了で、残りの段は実際の軌道を基準に計画し直される。手前で止めたなら、ノードは残りの Δv を持ったまま残る。自動噴射は残りちょうどで自分で止まる。
- 自動噴射装置と転送計算機は造船所で買える。なくても入港できる。
- 星図の◆は港（採掘・氷採取・ガス採取・精錬所・化学プラント・燃料プラント・農業・医療・工場・都市）、◇は補給ステーション、▲は造船所、●はコロニー、■は要塞、★は首都、◎はゲート。どれにも入港でき、入港はすべてチェックポイントになる。燃料（3）、生命維持（4）、船体（5）は有料で、どのステーションでも買える。モジュールは造船所でだけ買える。
- ステーションの数は宙域ごとに違う。どの宙域にも港が2つ以上、コロニーと造船所が1つ以上ある。コロニーは需要が大きく、そこへ向かう仕事が多く報酬も高い。積荷の健全度は回復しない。
- 天体の多い星系のいくつかは拠点で、互いに取引する2〜4のステーションが並ぶ。軌道図には星系のステーションがすべて出て、タップで相手を選ぶ（入港できるのは選んだステーション）。同じ星系内への仕事も出る（亜光速だけで届き、報酬は低い）。新しい銀河はこうした拠点の星系から始まり、最初の仕事は同じ星系の別の港への配達になる（FTLなしで、軌道合わせと入港を覚えられる）。
- 各勢力には首都が1つ、敵から遠い奥の拠点にある。大量に消費するので仕事が集まり報酬も高い。首都への納品や売却はスタンディングが1.5倍上がり、友好の会社には特命の仕事（遠くの自勢力の港へ封緘品を運ぶ、報酬が高い）を出す。首都が無傷なほど勢力の要塞はよく撃ち、首都は装甲があって少しずつ直るが、落ちうる。陥落すると要塞の火力が0.7倍に落ち、60日後に残った領土の最も安全な星系へ遷都する。
- 航海は港に停泊した状態で始まる。港の施設（Enter）を使えるのは停泊中だけで、配達と補給も入港して行う。
- 停泊中に使える航法機能は星図、マニューバ計画、発進計画の確認、時間の進行だけ。操船と発進は U で出港してから。出港直後で港のすぐそばなら U で入港し直せる。
- 停泊中は生命維持が減らない。発進の時機を待つ時間は無料で、出港すると消費が始まる。
- 銀河はいくつかの宙域（リージョン）に分かれる。宙域の境は地続きで、FTLでそのまま越えられる。ミッションの行き先は同じ宙域か、ゲートでつながった宙域。
- ゲート（星図の◎、破線が行き先）は宙域どうしを対でつなぐ。出港してから「ゲート通過」（下のボタンかゲートの右クリック）で予約し、ゲートの入港距離まで寄ると向こうのゲートへ出る。ゲートに対する相対位置と相対速度は、ゲートの軌道の向きを基準にそのまま引き継がれる。通行税は船・モジュール・積荷の価値の8%で、次の入港で精算される。予約しなければ普通のステーションとして入港できる（仕事は出さない）。
- 星系には惑星と衛星があり、それぞれヒル球を持つ。主天体はヒル球の出入りで恒星→惑星→衛星と切り替わり、予測線はその先の天体まで続く。ステーションは種別に応じて恒星（小惑星帯）、惑星、衛星を回る。
- ステーションには種別（農業、工業、研究、医療、小惑星採掘、都市、補給）があり、ミッションボードの品目は種別で決まる。報酬は積荷と直線距離で決まる。届くかどうかの保証はなく、中継を含めた経路はプレイヤーが考える。ボードは配達のたびに入れ替わる。
- 積荷には液体・加圧液体・バラ積み・コンテナの4種類があり、船のベイのうち種類の合うものにしか積めない。加圧液体は、加圧モジュール（造船所で液体ベイ1つごとに買う）を付けた液体ベイに積め、そのベイには普通の液体も積める。ベイの構成は船ごとに固定で、最初の船はコンテナベイ 160 m³ だけ。どのボードも1件目はコンテナの仕事。
- 船は複数持てる。造船所で買った船はその港に置かれ、乗っていない船は最後に入港した港で待つ（星図に「自船×N」）。乗り換えは船が置いてある港ならどこでもでき、降りた船は積荷・燃料・モジュールをそのまま持って残る。造船所では、積荷のない船を半値（船体の傷みとモジュールも反映）で売れる。破産の判定は、今いる港にある船のどれも出港できないとき。
- 船種は大きさ（小型・中型・大型）と用途（コンテナ船・タンカー・ガス運搬船・バラ積み船・混載船）の組み合わせ。空のときのΔvは大きさでは変わらず、大きい船ほどFTLの抵抗が大きく（×1.3、×2）、推力が弱く（×0.8、×0.5）、大型船はゲートを通れない。ガス運搬船は最初から加圧ベイで、加圧の容器のぶん重い（加圧モジュールも同じだけ重くなる）。混載船は小型・中型だけで、何でも積めるかわりに、同じ大きさの専用船より容積が2割少なく、重く（Δvが低い）、高い。造船所ごとに造る船種が違い、小型コンテナ船はどこでも造る。
- 航行中は I（またはコンソールの「積荷」）で積荷と仕事の窓を開ける。ベイごとの空き、各仕事の行き先・残りの距離・報酬・健全度・耐熱、ほかの港に置いた船が見え、仕事の行き先を針路にできる。
- 経済: 各ステーションは品目ごとに在庫と目標量を持ち、在庫が目標に対してどれだけあるかで価格が決まる（目標ちょうどで基準価格、尽きると約1.8倍、満杯で約0.55倍）。生産ラインは入力がある分だけ、作る物のどれかに置き場があるうちは動き（満杯の副産物は捨てる）、電力（核融合燃料か核分裂燃料）がなければ止まる。同じ宙域のステーションどうしは、近いほど強く在庫が均される（NPCの流通の代わり）。宙域をまたぐ品物は船でしか運ばれない。ステーションの種類は星系の天体に合わせて決まり（ガス採取はガス惑星、採掘は小惑星帯）、どの種類も銀河のどこかに必ずある。
- 港の画面は「仕事と積荷」「市場」「船」のタブに分かれる。市場では、そのステーションが作る物を買い、使う物を売れる（自由交易）。1単位ごとに在庫が動くので、まとめて買うほど高く、まとめて売るほど安くなる。買った品は「自分の荷」として船倉に積まれ、種類の合うベイが要る。燃料（核融合燃料）はどのステーションでも港の在庫から買え、在庫がなければ買えない（品切れ）。「10日待つ」で停泊したまま時間を進め、在庫の回復を待てる。破産は、今いる港の燃料価格で、持ち金をすべて使っても出港できる燃料を買えないとき。
- 売り買いは品目ごとのスライダーで数量を選び、確定ボタンで行う。船に合うベイがない品目は赤の打ち消し線で表示される。
- ほかの港の様子は、知らせが届いた分だけ古い情報として見える。知らせは在庫が均されるのと同じつながりを伝わり（同じ宙域なら1日に1.5光年、ゲートの対は1日）、5日ごとの記録が90日分残る。市場タブの「ほかの港の相場」で品目ごとに買える所と売れる所を、星図の右クリックで港の燃料と「港の情報（市場・仕事）」を、何日前の知らせかと一緒に見られる。着いたときの様子は変わっている。
- 仕事のうち、品目の仕事は、そのステーションの余った在庫を、その品目を使っていて足りないステーションへ運ぶ。報酬は両地点の価格差（最低でも基準価格の2割）と距離で決まる。請けると積み地の在庫から引かれ、届けると届け先の在庫に入る（傷んだ分は減る）。ボードは入港ごとに貼り出され、1件請けても残りは変わらない。最初の1件は仕事専用の品（冷凍種子・美術品など）。
- ベイの空きが許す限り複数のミッションを同時に請けられる。積荷は質量で船のΔvを減らし、耐熱も品目ごとに違う。請けた仕事は港で破棄できるが、報酬の25%を支払う。燃料、船体、生命維持は配達後も引き継ぐ。
- 目的地はミッションの行き先から選ぶほか、星図の右クリックでどの恒星にも設定できる。設定した目的地はその港に入港するまで保たれ、解除すると積荷の行き先（なければ最寄りの港）に戻る。
- 寄港先で、残燃料と買える燃料を足しても0.8に届かないと破産し、再開できずにその銀河が終わる。
- 窓の外の空は真実で、星図と予測は誤差を含む。誤差は飛行とともに増え、天測で戻る。星図は星に近づくほど正確になる。
- 窓の外の空には、光の通り道が効く。近くの恒星の質量は背後の星の光を曲げて二重像にする（実際の恒星では角度にして秒の単位なので、見えるように20万倍に誇張している）。FTL中は泡が空を歪め、星は進行方向へ寄り集まって前方は青く明るく、後方は赤く暗くなり、真後ろには光の届かない暗黒域ができる（速いほど強い。実際の超光速では前方の一点を残して真っ暗になるので、速度に応じて押さえている）。泡が解ける（降下・失速）と、前方が閃光で光る。星図の印と予測は星の本当の向きを指すので、速いほど見える星は印から前へずれる。
- 死亡すると、入港時のチェックポイントから再開するか、その銀河を終えるかを選ぶ。
- セーブは会社（銀河）ごとに1つで、いくつでも並べて持てる。タイトルに新しい順に並び、場所・銀河暦・配達数・資金が出る。銀河の作りが変わった古い版のセーブは一覧に残るが続けられない。以前の版の1つだけのセーブは、そのまま一覧に移る。
- タイトルの背景は、タイトル専用の銀河でのコックピットからの眺め。どこかの星系の惑星や衛星のそばに浮かぶ場面と、FTLで星の間を渡る場面が、暗転を挟んで順に流れる。

## 構成

- `sim/`: Godot非依存の計算コア。数値調整は `sim/Tuning.cs`。
