# Starbearer

超光速航行が弾道飛行に限られた銀河で、荷物を運ぶゲーム。移動そのものがゲーム。

## 起動

    dotnet build Starbearer.csproj
    godot-mono --path .

## 操作

| 場面 | 操作 |
|---|---|
| 軌道 | 軌道をタップしてノード追加（噴射後の軌道にも置ける）、ノードをタップでハンドル表示、ハンドルをドラッグで噴射調整（Shiftで精密）、ノードをドラッグで時刻変更、W/S・A/D・Q/Eでも調整、[ ]で段切替、Hで遷移案、Mで合流案、Backspaceか削除ボタンで削除、Shift+Backspaceで全削除、ドラッグで回転、2本指で移動、ピンチで拡大、Pで時間の停止と再開（停止中は機首も止まる）、Yで現在の軌道から再計画、Nで点火の手前まで時間を加速（着いたら実時間に落ちる）、I/Kでスロットル増減（Shiftで精密）、Oで全開、Lでゼロ、Spaceで機首方向へ点火と停止、矢印で機首、Xで港へ接近、Zで相対速度0、Jで発進計画、1-6で時間（x1が実時間）、Tabで空、Uで出港と入港、停泊中はEnterで港の施設 |
| 発進計画・修正 | タップで方位、矢印で微調整（Shiftで精密）、W/Sまたはホイールでキック量、2本指かドラッグで視点、Tabで星図、Enterで実行、Escで取消 |
| 星図 | タップで方位、ダブルタップでその星を中心に、2本指で中心を移動、ドラッグで回転、ピンチで拡大、Rで自機へ、Tで目的地へ |
| FTL飛行 | 矢印で機首、I/Kでスロットル増減（Shiftで精密）、Oで全開、Lでゼロ、Spaceで機首方向へ点火と停止、Dで降下、Fで天測、Cで修正計画、Vか姿勢儀のタップで姿勢保持、Bでカメラを機首に固定、1-6で時間（x1が実時間）、2本指かドラッグでカメラ、Tabで星図 |
| 港のウィンドウ | Enterで開く。ボタンをクリックしてミッションを請ける、破棄する、針路を選ぶ、補給する。1, 2でモジュール、3, 4, 5で補給、Enterで船へ戻る |

軌道線は閉じた1周ぶんを矢印付きで描く。天体の重力圏を出るなら線はそこで切れ、端に Disengage の時刻、次の星のヒル球に入るなら Encounter の時刻と、その星を通過する軌道が緑で続く（さらに先も最大3星ぶん）。先の軌道にも恒星間の破線にもノードを置ける。無推力の軌道は変わらないので、線の再計算は噴射・ノード編集・主天体の切り替えなどのときだけ行う。

星図は1枚で、亜光速の軌道図を縮小すると銀河まで続き、計画後に発進した場合のFTL経路も見える。FTLの星図を拡大すると港の軌道と、今降下した場合の軌道が見える。

画面下の操作盤はキーと同じ働きをする。その時に押せないボタンは暗くなり、次にやるとよい操作は「次の一手」の文と光るボタンで示す。画面の四隅の括弧は船の状態を色で示し（緑 亜光速、青 FTL、橙 井戸や計画中、赤の点滅 失速の危険）、発進・降下・脱落は全画面の演出で知らせる。

## 基本ルール

- 空間は2層ある。亜光速層は恒星の重力だけの3D軌道力学で、FTL層は弾道飛行。速度はそのまま引き継ぐ。
- 重力は主天体1つだけで解く。ヒル球の内側はその星との2体問題、外側は直進で、ほかの星の影響は受けない。ヒル球の外を亜光速で進むと、次の星のヒル球に入った時点で主天体が替わる。ヒル球の外ではノードを計画できない。
- 発進は港の軌道から。軌道速度がキックに加わるので、向かい風の時機に出ると燃料を損する。
- FTLでは抵抗で速度が距離とともに指数的に落ち、閾値を下回ると失速する。星雲の中は抵抗が強い。
- 恒星の井戸でだけ曲がる。深く通るほど曲がり、井戸の底で噴くほど効率がよく、燃料も吸える。ただし熱い。機首を恒星に向けるとシールドが効く。
- 目的地の井戸で降下すると亜光速の軌道に入る。降下は井戸の中ならどの星でもできる。
- 入港はマニューバノードで港の軌道に合わせ、距離と相対速度を条件内に収める。点火すると計画軌道は固定され、白線が今止めた場合の軌道になる。段が終わると、残りの段は実際の軌道を基準に計画し直される。
- 自動噴射装置と転送計算機は拠点で買える。なくても入港できる。
- 星図の◆は港、◇は補給ステーション。どちらにも入港でき、入港はすべてチェックポイントになる。燃料（3）、生命維持（4）、船体（5）は有料で、どの港でも買える。積荷の健全度は回復しない。
- 航海は港に停泊した状態で始まる。港の施設（Enter）を使えるのは停泊中だけで、配達と補給も入港して行う。
- 停泊中に使える航法機能は星図、マニューバ計画、発進計画の確認、時間の進行だけ。操船と発進は U で出港してから。出港直後で港のすぐそばなら U で入港し直せる。
- 停泊中は生命維持が減らない。発進の時機を待つ時間は無料で、出港すると消費が始まる。
- 星系には惑星と衛星があり、それぞれヒル球を持つ。主天体はヒル球の出入りで恒星→惑星→衛星と切り替わり、予測線はその先の天体まで続く。ステーションは種別に応じて恒星（小惑星帯）、惑星、衛星を回る。
- ステーションには種別（農業、工業、研究、医療、小惑星採掘、都市、補給）があり、ミッションボードの品目は種別で決まる。報酬は積荷と直線距離で決まる。届くかどうかの保証はなく、中継を含めた経路はプレイヤーが考える。ボードは配達のたびに入れ替わる。
- カーゴの容積（8）が許す限り複数のミッションを同時に請けられる。積荷は質量で船のΔvを減らし、耐熱も品目ごとに違う。請けた仕事は港で破棄できるが、報酬の25%を支払う。燃料、船体、生命維持は配達後も引き継ぐ。
- 寄港先で、残燃料と買える燃料を足しても0.8に届かないと破産し、再開できずにその銀河が終わる。
- 窓の外の空は真実で、星図と予測は誤差を含む。誤差は飛行とともに増え、天測で戻る。星図は星に近づくほど正確になる。
- 死亡すると、入港時のチェックポイントから再開するか、その銀河を終えるかを選ぶ。

## 構成

- `sim/`: Godot非依存の計算コア。数値調整は `sim/Tuning.cs`。
- `game/`: Godot側の描画、入力、画面遷移。
- `tests/Starbearer.Sim.Tests`: `dotnet test tests/Starbearer.Sim.Tests`
- `tests/balance`: 自動パイロットで契約を飛ばす調整用ツール。`dotnet run -c Release --project tests/balance`
- 通し確認: `godot-mono --path . -- --autotest=<スクリーンショット出力先>`
